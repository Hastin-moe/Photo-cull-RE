# 灰度测试计划 · 照片工具 Pre-A

写于 2026-11-21，11-22 改为一个共用激活码、发布包只放成品。日期都是建议，按你的节奏改；改了在这里更新。

## 1. 目的

在小范围真实用户的 Mac、真实照片上，确认 Pre-A 可以稳定地**安装 → 激活 → 筛片 → 整理**，并收集：

1. 会让人用不下去的问题（闪退、卡住、激活失败、照片丢失或被误挪）；
2. 筛片结果是否靠谱（糊片、眼部偏软、精选是否合理）——尤其是**不同相机、不同题材**下的表现（目前眼部提示线只用一批索尼 cosplay 校准过）；
3. 流程是否看得懂（流程卡片模式、高级模式、报告）。

**不在这次范围内**：胶片冲印（单独的 GPL 插件，不随灰度包发）、Windows、Intel Mac（见第 3 节）。

## 3. 测试的人

- **10 人**，用**一个共用激活码**（11-22 用户定：作者自己定的码，知道的人才能试用；不写进任何文件，应用里只有哈希）。做发布包时建议设 2027-01-31 到期。
- 要求：**Apple 芯片的 Mac**（M1 及以后）。应用是在你的 M4 Pro 上打包的，只有 Apple 芯片的版本；Intel Mac 打不开。系统 macOS 11 以上可以用，**macOS 14 以上才有完整的苹果 Vision 识别**（猫狗姿态；美感分要 15 以上）。
- 尽量覆盖：不同相机品牌（索尼／佳能／尼康／富士／松下）、RAW 和 JPEG、人像／活动／街拍／宠物／风光、几百到上千张的批次。
- 建议分两轮：

| 轮 | 人数 | 编号 | 目的 |
|---|---|---|---|
| 第一轮 | 3 人（熟悉、能耐心描述问题的） | 名单 1～3 | 先过安装、激活、基本流程；有大问题在小范围内修 |
| 第二轮 | 再加 7 人 | 名单 4～10 | 更多相机和题材，看筛片质量 |

## 5. 测什么（测试的人照《测试者须知》做，这里是你看结果时的重点）

| # | 重点 | 怎么看出问题 |
|---|---|---|
| A | 安装、打开（未签名应用） | 测试的人卡在「无法打开」「已损坏」→ 看须知里的办法是否够清楚 |
| B | 激活 | 激活页只有一个输入框；输对能进、输错提示；重开不再问 |
| C | 流程卡片模式从头走到结果 | 每一步看得懂吗、哪一步犹豫了 |
| D | 常规筛片＋整理（复制模式） | 整理完那句话的四个数加起来等于总张数；精选／可用／连拍放对了；原片没丢 |
| E | 糊片和「眼部偏软」 | 标了眼部偏软的是不是真的软；漏掉的明显糊片（请测试的人举例，附运行记录） |
| F | 识别方式（默认混合） | 运行报告「识别方式」一行；有没有大量「出错改用 OpenCV」 |
| G | 快速筛片 | 挑出的 8／16／32 张是不是想要的 |
| H | AI 细评（可选，测试的人自己的 API Key） | 费用确认弹窗、评语质量；没有 Key 的人只测本地 |
| I | 大批量 | 上千张不闪退；运行报告里的用时、内存 |
| J | 关闭、再打开、载入上次结果 | 结果还在；改过的分还在 |

## 6. 问题分级（写在反馈记录里）

| 级 | 意思 | 处理 |
|---|---|---|
| **严重** | 闪退、卡死、激活不了、**照片丢失或被挪到找不到的地方** | 马上回复测试的人先停用；修好打新版本再继续 |
| 一般 | 结果明显不对（误判糊片、整理分错）、某个功能用不了 | 这一轮内修 |
| 轻微 | 文字、排版、动效、不顺手 | 记下来，攒着一起改 |
| 建议 | 想要的新功能 | 灰度结束后统一看 |

## 7. 结束条件

满足以下全部，才算 Pre-A 灰度通过：

- 没有未处理的「严重」；「一般」都有结论（修了，或明确不修并写明原因）；
- 至少 6 人完整用过两批以上照片，交回结束问卷；
- 至少 3 个不同相机品牌的照片筛过；
- 你自己的 Mac 上，开发版测试全过、灰度版打包自检通过。

## 8. 结束问卷（灰度快结束时发给测试的人）

1. 你用的 Mac 型号和系统版本？筛了几批、大概多少张、什么相机、什么题材？
2. 安装和激活顺利吗？哪一步卡住过？
3. 筛片结果：精选的照片你同意的大概占几成？有没有明显糊的被选进来、或者好照片被淘汰？
4. 「眼部偏软」的提示准吗？
5. 流程卡片模式和高级模式，你更常用哪个？为什么？
6. 最想改的一处是什么？最喜欢的一处是什么？
7. 愿不愿意继续用正式版？

## 9. 风险和应对

| 风险 | 应对 |
|---|---|
| 照片被误挪或误删 | 须知里第一条就写「先用照片副本测」；整理默认复制；收到这类反馈按严重处理 |
| 激活码被转给别人 | 只有一个码、不绑电脑，传出去就谁都能用：只告诉名单上的人、单独告诉；设到期日；真被乱传就换码重新做发布包、只发给名单上的人（旧包仍能用旧码，所以要配合新版本）。码是个短数字的话，懂行的人能从应用里试出来——这只防随手转发 |
| 打不开（未签名、Intel Mac） | 须知里写清楚；Intel Mac 的人不发 |
| 测试的人的 AI 费用 | AI 细评可选；须知里提醒有确认弹窗、先小批量试 |
