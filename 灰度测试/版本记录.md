# 灰度版本记录

每次做发布包（`tools/导出发布版.command`）发给测试的人，记一笔。zip 名里带日期时间（`PhotoCull-Pre-A-<日期时间>-macOS.zip`），这里给它一个构建号 G1、G2……；`photo-cull-main-release/发布记录.md` 里有每个包的 SHA-256 和打包源码指纹。

**开发版指纹**：导出前在开发版里算（和 Claude 核对写回时用的是同一种）：
```
cd ~/Desktop/Dev/photo-cull-main
find . -type f -not -path "./.venv*" -not -path "./.git/*" -not -path "./luts/*" -not -path "*/__pycache__/*" -not -name ".DS_Store" -not -path "./dist/*" -not -path "./build/*" | sort | xargs md5sum | cut -c1-8 | md5sum
```

|---|---|---|---|---|---|---|
| G1 |  |  |  |  | 名单 1～3 | 第一个发布包（共用激活码） |
